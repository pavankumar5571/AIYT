# AI-YouTube · Build Dashboard

A Next.js dashboard showing the **progress** of each AI-generated story video through
the pipeline (Modules 04–13) and the **cost** to generate it.

Data comes from a committed `data/builds.json`, generated by scanning the pipeline
output. This makes the app fully static and deployable to Vercel — no database, no
access to your local machine required.

## How the data flows

```
C:\AI-Youtube\output\**   ──(collect-builds.mjs)──►  dashboard/data/builds.json  ──►  Next.js (Vercel)
```

Vercel can't read your local files, so the dashboard renders the **committed**
`data/builds.json`. To update the live dashboard, regenerate it and push.

## Refresh the data (run on the machine with the pipeline)

Host has no Node? Use Docker (the whole project is mounted so it can read `../output`):

```powershell
docker run --rm -v C:/AI-Youtube:/work -w /work/dashboard node:20-alpine node scripts/collect-builds.mjs
```

Or, if you have Node installed:

```bash
cd C:/AI-Youtube/dashboard
npm run collect
```

Then commit + push so Vercel redeploys:

```bash
git add data/builds.json && git commit -m "refresh builds" && git push
```

> Upload results (YouTube URL/privacy) aren't written to disk by the pipeline —
> record them in `data/uploads.json` (id → details); the collector merges them in.

## Local dev

```bash
npm install
npm run dev      # http://localhost:3000
```

No Node on the host? Run dev in Docker:

```powershell
docker run --rm -it -p 3000:3000 -v C:/AI-Youtube/dashboard:/app -w /app node:20-alpine sh -c "npm install && npm run dev -- -H 0.0.0.0"
```

## Deploy to Vercel

The app is a standard Next.js 14 App Router project — Vercel builds it in the cloud
(no local Node needed to deploy).

**Option A — Vercel CLI**

```bash
cd C:/AI-Youtube/dashboard
npx vercel          # first run: log in + link the project
npx vercel --prod   # production deploy
```

**Option B — GitHub + Vercel dashboard**

1. Push this `dashboard/` folder to a GitHub repo.
2. On vercel.com → **New Project** → import the repo.
3. If the repo root is the whole `AI-Youtube` project, set **Root Directory** to `dashboard`.
4. Framework preset **Next.js** is auto-detected. Click **Deploy**.

No environment variables are required.

## Cost model

Real spend is **$0** (Gemini free tier, edge-tts, local FFmpeg). The dashboard also
shows an *equivalent paid-API* estimate per step so you can see what the work would
cost at scale. Pricing constants live at the top of `scripts/collect-builds.mjs`.
